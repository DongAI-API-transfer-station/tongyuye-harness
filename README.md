# 同于野

[下载最新版本](https://github.com/DongAI-API-transfer-station/tongyuye-harness/releases/latest)

## r7

- 安装改为 ZIP 直接解压。同内容隔离对比覆盖安装约 143 秒 → 53–57 秒；安装包约 220 MiB。
- 中转站视频模型仅发送本次用户输入，避免 Agent 系统提示词、技能和工具定义导致提示词超限。
- 常见视频模型自动识别；未知名称可在模型更多设置中指定“视频生成（中转站）”。避免自动标题额外调用视频模型。
- 451 项相关测试通过，实际 Windows 视频请求、设置保存和独立安装验证通过。
- 视频适配针对聊天兼容中转接口，不代表各厂商原生异步视频 API 均已支持；未使用真实模型额度完成生成验证。

## r6（已包含）

- 优化完全退出后启动，本机三轮中位数 4.58 秒 → 3.06 秒，减少约 33%。
- 点击 X 隐藏到托盘，后台任务继续；托盘提供打开与完全退出。
- 移除首页“预览版 / Preview”标记。
- 相关测试 162 项通过，实际 Windows 后台执行、恢复及首页验证通过。
- 时间为同机隔离配置实测，未重启系统或清空系统文件缓存；不同机器可能不同。

## r5（已包含）

- 点击模型名称直接展开可切换模型，保留推理等级设置。
- 简化提供方设置：隐藏内置“添加提供方”，自动生成 Provider ID。
- 更新系统提示词、上下文注入、对话及轨迹中的产品显示名称。
- 请求等待状态显示“思考中…”。
- 保留 r4 的盘符根目录新建会话修复。

Release 提供 Windows x64 安装包、供 Apple 芯片 Mac 编译的源码 ZIP 和 SHA-256 校验文件。Mac ZIP 是源码，不是 Mac 安装包。

应用内部版本：0.1.5-rc.2。Windows 为未签名构建。安装更新不会自动删除已有聊天记录或模型配置。

相关回归测试 620 项通过，已在隔离数据下验证 Windows 桌面交互。Mac 编译尚未验证，编译步骤见源码包内的 MAC编译说明.md。
